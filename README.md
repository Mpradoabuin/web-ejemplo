# Consorcio Cádiz

Web explicativa del proyecto de inteligencia artificial aplicado a la gestión de
expedientes periciales del Consorcio de Compensación de Seguros.

## Uso

Es una web estática sin proceso de compilación. Abre `index.html` en un navegador
o publica la carpeta directamente mediante GitHub Pages.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: diseño adaptable para escritorio y móvil.
- `script.js`: recorrido interactivo, cambio de capacidades y menú móvil.
